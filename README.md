## License & mods

GPLv3 — anyone may play, host, or build on it (commercial use included), but redistributions keep the copyright notice and publish their source under the same license. That keeps the creator credit in every copy: the signature travels with the paper.

Mods are welcome as **add-on pull requests** (label them `mod:`) — core changes are reviewed as proposals. How modding works for a server-streamed APK game: [MODS.md](MODS.md).
